# Boca Bot

Panel responsive de preferencias para sectores de Boca Socios. **Actualmente es una demo de interfaz**: no monitorea el sitio, no selecciona plateas, no envía WhatsApp y no comparte configuraciones entre dispositivos.

## Ejecutar localmente

```bash
npm install
npm run dev
```

Abrí http://localhost:3000.

## Publicar en Vercel

1. Ingresá a https://vercel.com/new.
2. Importá `Joaquincoronell/Boca_bot` desde GitHub.
3. Elegí Next.js y pulsá Deploy.

Para tener un bot real, se necesita un servidor independiente con una integración autorizada, autenticación privada, persistencia y gestión segura de credenciales. No se deben subir cookies, contraseñas, API keys ni archivos `.env` a GitHub.
